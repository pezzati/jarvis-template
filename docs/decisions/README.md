# Architecture Decision Records

ADRs freeze a choice after an RFC is **accepted**. They are not a second RFC.

- Template: [0000-template.md](0000-template.md)
- Number **NNNN matches the RFC number**
- `RFC:` must point at the RFC's **current** path (it moves between `docs/rfcs/<status>/`)

Write ADRs with `/rfc-accept`. If codebase-memory MCP is up, also `manage_adr`.
