# Plans

`/plan` writes `MMMM-slug.md` here. `MMMM` is the **ADR** number, not the RFC number.

Requires an RFC in `docs/rfcs/accepted/` and a named ADR. One plan per ADR.

This is detailed design: components, APIs, files, sequence. Not a rewrite of the RFC.

Template: [0000-template.md](0000-template.md).
